# 작업 지시서: 음성 인식

## 목표
사용자가 말한 문장을 의도로 바꾸고, 결과를 음성으로 답한다.

## 담당 파일
- `frontend/js/voice.js`: 마이크 입력(STT), 음성 출력(TTS)
- `backend/app/services/command_parser.py`: 문장 → 의도 규칙
- `backend/tests/test_command_parser.py`: 예문 테스트

## 현재 상태
"할 일 추가 OO", "할 일 알려줘", "멈춰", "안녕" 네 가지 의도가 동작합니다.

## 5일 작업
| 요일 | 작업 | 완료 기준 |
| --- | --- | --- |
| 월 | 코드 읽기, 브라우저에서 음성 명령 4종 직접 테스트, 인식 실패 문장 기록 | 실패 사례 10개 이상 정리 |
| 화 | 의도 추가: 할 일 완료("우유 사기 완료"), 작업 시작("공부 시작할게") | 테스트 예문 각 3개 이상 통과 |
| 수 | 말하는 중 손바닥 제스처로 정지 연동 확인, 연속 듣기 모드(버튼 한 번에 여러 문장) 검토 | 정지가 1초 안에 동작 |
| 목 | 표현 다양화(동의어, 띄어쓰기 변형), 모르는 명령 응답 다듬기 | 실패 사례 목록의 80% 처리 |
| 금 | 시연 문장 확정, 리허설 | 시연 문장 100% 성공 |

## 협업 포인트
- 새 의도가 DB 작업을 필요로 하면 백엔드 담당과 `api/assistant.py` 수정을 함께 합니다.
- 작업 시작 의도는 `task_started` 이벤트를 남겨야 추천에 반영됩니다 (데이터 엔지니어링과 확인).

## 주의
- Web Speech API는 Chrome에서 가장 안정적입니다. 시연은 Chrome으로 합니다.
- 인식이 안 되는 환경을 위해 텍스트 입력창은 항상 유지합니다.
