# 작업 지시서: 프론트 (대시보드)

## 목표
사용자가 비서의 상태와 기록을 한 화면에서 보고 조작할 수 있게 한다.

## 담당 파일
- `frontend/index.html`, `frontend/style.css`
- `frontend/js/dashboard.js`: 할 일, 이벤트 로그, 시간대 차트, 추천 표시
- `frontend/js/app.js`: 모듈 연결 (음성, 모션 담당과 공동)
- `frontend/js/api.js`: 서버 호출

## 현재 상태
빌드 도구 없이 HTML과 JavaScript 모듈로 동작합니다. FastAPI가 같은 주소로 화면을 제공합니다.

## 5일 작업
| 요일 | 작업 | 완료 기준 |
| --- | --- | --- |
| 월 | 화면 구조 확정(와이어프레임), 레이아웃과 상태 표시 정리 | 팀 합의된 화면 구성 |
| 화 | 추천 카드에 수락, 거절 버튼 → `recommendation_feedback` 이벤트 전송 | 버튼 클릭이 DB에 기록 |
| 수 | 시간대 차트 개선 (축, 현재 시간 강조), 이벤트 로그를 사람이 읽기 쉬운 문장으로 | 로그가 "09:12 손바닥 인식"처럼 보임 |
| 목 | 지표 카드(수락률, 오늘 이벤트 수), 카메라와 마이크 사용 동의 안내 | 지표가 데이터에 따라 바뀜 |
| 금 | 시연 흐름에 맞춰 화면 다듬기, 버그 수정 | 시연 중 화면 오류 없음 |

## 협업 포인트
- 서버에 없는 데이터가 필요하면 백엔드 담당에게 API를 요청하고, 그 전까지는 가짜 데이터로 화면을 먼저 만듭니다.
- `app.js`는 여러 명이 고치므로 작은 PR로 자주 병합합니다.

## 주의
- 카메라와 마이크는 `localhost` 또는 HTTPS에서만 동작합니다.
- React 전환은 MVP 이후에 검토합니다. 지금은 구조를 단순하게 유지합니다.
