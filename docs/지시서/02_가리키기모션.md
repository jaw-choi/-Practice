# 작업 지시서: 가리키기 모션

## 목표
웹캠으로 손동작과 검지 가리키기를 인식해 안정적인 이벤트로 바꾼다.

## 담당 파일
- `frontend/js/vision.js`: MediaPipe 실행, 가리키기 판정, 이벤트 전송 조건

## 현재 상태
- MediaPipe Gesture Recognizer 기본 제스처(Open_Palm, Victory, Thumb_Up 등) 인식
- 검지만 펴면 가리키기로 판정, 방향(상하좌우)과 화면 위치(빨간 점) 표시
- 8프레임 연속 같은 결과일 때만 인정, 같은 이벤트는 2초에 한 번만 전송

## 5일 작업
| 요일 | 작업 | 완료 기준 |
| --- | --- | --- |
| 월 | 코드 읽기, 조명과 거리별 인식 테스트, `STABLE_FRAMES`와 `COOLDOWN_MS` 값 조정 | 오인식 사례와 적정 값 기록 |
| 화 | 가리키기 대상 정하기: 화면을 영역(예: 3x3)으로 나눠 어느 칸을 가리키는지 `zone` 추가 | payload에 `zone` 포함, event-schema.md 갱신 |
| 수 | 가리킨 영역에 기능 연결 (예: 할 일 카드를 가리키면 할 일 읽어주기) 프론트와 협의 | 시나리오 1개 동작 |
| 목 | 인물 부재 감지: 손이나 얼굴이 N초 안 보이면 `presence_changed` 전송 | 자리 비움과 복귀 이벤트 기록 |
| 금 | 시연 동작 리허설, 실패 시 대체 동작 준비 | 시연 동작 3회 연속 성공 |

## 협업 포인트
- 이벤트 형식을 바꾸면 반드시 `docs/event-schema.md`와 `backend/app/schemas.py`를 같이 고칩니다.
- 화면 표시(점, 라벨)는 `app.js`의 `onResult`에서 처리합니다. 큰 UI 변경은 프론트 담당과 상의합니다.

## 주의
- 손 흔들기(wave)는 기본 모델에 없어서 현재 Victory로 인사를 대신합니다. 시간이 남으면 손목 좌우 이동량으로 직접 구현합니다.
- 영상 프레임이나 이미지는 절대 서버로 보내지 않습니다.
