# 작업 지시서: 데이터 엔지니어링

## 목표
쌓인 행동 로그에서 반복 패턴을 찾아 추천으로 바꾸고, 그 결과를 측정한다.

## 담당 파일
- `backend/app/services/patterns.py`: 집계와 추천 규칙
- `backend/app/models.py`: 테이블 구조 (백엔드와 공동)
- `analytics/seed_demo_data.py`: 시연용 데이터
- `analytics/explore.py`: Pandas 분석

## 현재 상태
- 시간대별 이벤트 수 집계 (`/stats/hourly`)
- 최근 7일 중 4일 이상 같은 시간에 `task_started`가 있으면 추천 1개 (`/recommendations`)

## 5일 작업
| 요일 | 작업 | 완료 기준 |
| --- | --- | --- |
| 월 | 시드 데이터 실행, explore.py로 로그 확인, 이벤트 표 검토 | 부족한 이벤트나 필드 목록 정리 |
| 화 | 추천 피드백 반영: `recommendation_feedback` 거절이 많으면 그 추천을 덜 보여주는 규칙 | 테스트로 거절 후 추천 감소 확인 |
| 수 | 추천 종류 추가 (예: 할 일이 쌓이면 정리 제안, 오래 자리 비운 뒤 복귀 시 이전 작업 안내) | 추천 2종 이상 동작 |
| 목 | 지표 계산: 추천 수락률, 거절률, 하루 알림 수. `/stats` 엔드포인트로 제공 | 대시보드에서 지표 확인 가능 |
| 금 | 시연 데이터 최종 정리, 발표용 분석 결과 정리 | 시연 시 추천이 확실히 뜸 |

## 협업 포인트
- 새 API는 백엔드 담당과 `api/stats.py`에 함께 추가합니다.
- 피드백 버튼 UI는 프론트 담당에게 요청합니다.

## 주의
- 시간은 DB에 UTC로 저장됩니다. 분석할 때 `to_local()`로 한국 시간으로 바꿉니다.
- 규칙의 숫자(7일, 4일)는 함수 인자로 두고 테스트로 검증합니다.
